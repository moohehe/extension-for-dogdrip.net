# extension for dogdrip.net

개드립(dogdrip.net)을 키보드로 편하게 탐색할 수 있는 Chrome 확장프로그램입니다.

---

## 단축키

| 단축키 | 기능 |
|---|---|
| `Ctrl + ←` | 목록에서 이전 게시글로 이동 |
| `Ctrl + →` | 목록에서 다음 게시글로 이동 |
| `Ctrl + ↓` | 하단 목록으로 스크롤 + 키보드 선택 모드 진입 |

### 키보드 선택 모드 (`Ctrl + ↓` 이후)

| 키 | 기능 |
|---|---|
| `↑` / `↓` | 목록 항목 이동 |
| `Enter` | 선택한 게시글로 이동 |
| `3` `4` `5` ... `q` `w` `e` ... | 해당 번호의 게시글로 바로 이동 |
| `ESC` | 선택 모드 종료 |
