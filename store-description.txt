github : https://github.com/moohehe/extension-for-dogdrip.net
개드립(dogdrip.net)용 키보드 단축키 확장 프로그램입니다.
개선사항/건의사항은 moohehe@hanmail.net으로 보내주세요.

■ 단축키
Ctrl+Left  : 목록에서 이전 게시글로 이동
Ctrl+Right : 목록에서 다음 게시글로 이동
Ctrl+Down  : 하단 목록으로 이동 + 키보드 선택 모드 진입
  - ↑ / ↓  : 목록 항목 이동
  - Enter   : 선택한 게시글로 이동
  - 3,4,5... / q,w,e... : 해당 번호의 게시글로 바로 이동
  - ESC     : 선택 모드 종료
